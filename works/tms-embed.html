TMS 02
판단
Key Decision
고치는 사람을 개발자에서
운영자로 옮겼습니다
자동 분류를 더 똑똑하게 만들거나, 사람이 고칠 수 있게 하거나. 예외가 남는 한 누군가는 손으로 고쳐야 한다는 점에서 두 번째를 골랐습니다.
두 갈래가 있었습니다
분류 알고리즘을 정교하게
정확도를 99%로 올려도 남은 1%는 여전히 사람이 품습니다. 고치는 경로가 없으면 개선분만큼 예외가 다시 쌓입니다.
소터로 보내기 전에 편집권을
자동 결과를 지도에 올리고, 운영자가 고쳐 확정한 뒤 소터로 넘깁니다. 자동 생성은 초안, 확정은 사람.
치른 비용 — 운영 단계가 하나 늘었습니다
확인 시간
소터 전송 전 사람이 보는 시간이 생깁니다
숙련도 의존
분류 품질이 운영자 숙련도에 묶입니다
책임 이동
잘못 편집하면 책임도 운영자에게 갑니다
대신 개발 요청 대기와 테이블 직접 수정이 경로에서 사라졌습니다
편집하려면 먼저 보여야 합니다
그래서 편집 기능보다 지도 시각화를 먼저 만들었습니다 (TMS 07).
자동화를 포기한 것이 아닙니다 — 바뀐 것은 결과를 확정하는 권한의 위치 하나입니다
자동 분류는 그대로 돌고, 데이터 기반 상 · 하차 경로 자동 생성도 그 위에 얹었습니다.
